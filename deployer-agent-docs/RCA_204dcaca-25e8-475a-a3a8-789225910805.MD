# Diagnostic Secrets — Intégration Paxity v2

**Demande :** vérifier la présence en production des 4 secrets backend de la nouvelle intégration Paxity v2. Lecture seule, aucun déploiement, aucune modification de secret.

## Méthode
`list_secrets` sur le run actif (`204dcaca-25e8-475a-a3a8-789225910805`, deployment `paxity-payment-web`), avec comparaison de valeur attendue (`equals`) pour `PAXITY_V2_API_KEY`. `metadata_available=true`.

## Résultats

### Secrets présents en production
CORS_ORIGINS, DB_NAME, ENABLE_HEALTH_CHECK, FRONTEND_URL, INTEGRATION_PROXY_URL, JWT_SECRET, MERCHANT_EMAIL, MONGO_URL, PAXITY_API_KEY, PAXITY_API_TOKEN, PAXITY_BASE_URL, PAXITY_DEFAULT_CURRENCY, PAXITY_DEFAULT_PREFIX, PAXITY_ENV, PAXITY_IPN_URL (vide), PAXITY_MAX_RETRIES, REACT_APP_BACKEND_URL, REACT_APP_SITE_GATE_ENABLED, REACT_APP_SITE_PASSWORD, REACT_APP_STRIPE_PUBLISHABLE_KEY, RESEND_API_KEY, SELLER_EMAIL, SELLER_PASSWORD, SENDER_EMAIL, STRIPE_ACCOUNT_ID, STRIPE_MODE, STRIPE_PUBLISHABLE_KEY, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, TEST_SELLER_EMAIL, TEST_SELLER_PASSWORD, WDS_SOCKET_PORT.

### Clés Paxity v2 attendues
| Clé | Présente en prod ? |
|-----|--------------------|
| PAXITY_V2_API_KEY | NON |
| PAXITY_V2_ORG_ID | NON |
| PAXITY_V2_BASE_URL | NON |
| PAXITY_V2_ENV | NON |

Aucune des 4 clés `PAXITY_V2_*` n'est présente. Des clés Paxity **v1** (`PAXITY_API_KEY`, `PAXITY_BASE_URL`, `PAXITY_ENV`…) existent mais portent des noms différents et ne seront pas lues par le code v2.

### Correspondance de valeur PAXITY_V2_API_KEY
NON — la clé n'existe pas, aucune valeur à comparer (`matches_expected` non renvoyé car clé absente). La valeur elle-même n'a jamais été exposée.

## Cause / Action
Les variables ajoutées dans le `.env` de la **preview** ne sont pas reportées automatiquement en production lors d'un redéploiement d'une app existante (seul le 1er déploiement initial les importe). L'utilisateur doit ajouter les 4 clés manuellement.

## Fix recommandé
Deployment Panel → Secrets : ajouter `PAXITY_V2_API_KEY`, `PAXITY_V2_ORG_ID`, `PAXITY_V2_BASE_URL`, `PAXITY_V2_ENV` avec les bonnes valeurs, puis redéployer.
